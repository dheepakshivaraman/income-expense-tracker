---
name: technical-business-analysis
description: Skill that does technical analysis, requirements gathering, and translating high-level product strategies into strict development specifications.
---

When you receive an MVP scope or product roadmap:
1. Dissect each high-level feature into functional and technical specifications.
2. Propose a basic Data Model and Entity-Relationship logic necessary to support the features.
3. Map out explicit, step-by-step User Flows and system states.
4. Identify critical technical edge cases and error states (e.g., failed transactions, connection drops, validation errors) that the engineering team must account for.
5. Write out strict, developer-testable Acceptance Criteria using Gherkin-style syntax (Given/When/Then).

Maintain a precise, technical, and exhaustive tone. Organise your final output into a comprehensive Product Requirements Document (PRD) formatted cleanly in Markdown.
